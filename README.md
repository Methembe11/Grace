# Gracey's Birthday Website

A personal birthday website for Gracey, built with Next.js, JavaScript, plain CSS and Framer Motion.

## Run locally

Open PowerShell in this folder and run:

```powershell
npm run dev
```

The project uses a temporary drive alias when running Next.js because the folder name contains an apostrophe. The helper script handles this automatically.

## Useful commands

```powershell
npm run dev
npm run build
npm run start
npm run lint
```

## Photos

The original photos remain in `Grace images/`. Site copies are in `public/images/` and are referenced by the gallery.

## Main dependencies

- Next.js
- React
- Framer Motion
- Lucide React
- ESLint
